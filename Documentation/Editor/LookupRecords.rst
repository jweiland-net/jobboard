===========================================
Occupational fields, positions and benefits
===========================================

The values that editors select in a job are records of their own. Create
them in the storage folder before you create jobs.

..  _editor-lookup-simple:

Records with a title only
=========================

These records have only one field, :guilabel:`Title`. It is required.

*   Occupational field (Berufsfeld), maximum 60 characters
*   Position (Position)
*   Type of employment (Beschäftigungsart), shown in the job as
    "Employment scope" (Stellenumfang)
*   Contract type (Vertragsart)
*   Tender type (Art der Ausschreibung)

Like all records of the job board, they have the usual fields
:guilabel:`Language` and :guilabel:`Enabled` on the first tab and a tab
:guilabel:`Access` with publish and expiration date. A hidden or expired
record is no longer shown in the job and in the search form.

The search form only offers occupational fields, positions and types of
employment that are used by at least one listed job.

..  _editor-benefit:

Benefit
=======

..  figure:: /Images/Editor/benefit.png
    :alt: Benefit record with the color picker and its quick-pick swatches
    :class: with-border with-shadow
    :zoom: lightbox

    A benefit with the color picker opened

:guilabel:`Benefit`
    Title of the benefit, for example "Job bike". Required.

:guilabel:`Color`
    Optional color. The color picker offers six pastel colors (Blue,
    Green, Orange, Pink, Purple, Yellow) as quick selection, but any other
    color is possible. The detail view shows the benefit with a border in
    this color.

:guilabel:`Description`
    Optional plain text.

:guilabel:`Image` (tab :guilabel:`Media`)
    Optional image, at most one file. Other file types can not be added.

Select the benefits of a job in its tab :guilabel:`Job Details`, palette
:guilabel:`Benefits`.
