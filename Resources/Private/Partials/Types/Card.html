Alternative rendering to Types/Table: renders each job as a card instead of a table row. List/Search render Types/Table by default, but either template can render this partial instead - keep it even if nothing in this extension itself references it yet, a consuming project may switch to it via template override. The markup is the same for every visitor (List is cached): remember-jobs.js adds "highlight-row" to remembered cards via data-jobboard-uid.
